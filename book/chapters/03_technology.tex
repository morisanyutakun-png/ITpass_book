\chapter{テクノロジ系：何でできているかを見る}

\section{ハードウェアとソフトウェアの棲み分け}

\pitfall{「OS」と「アプリ」と「ミドルウェア」の境界が曖昧}{
初学者が最初に混乱するのが、ソフトウェアの階層です。
\textbf{下から}ハードウェア → OS → ミドルウェア → アプリケーション、という\termtag{地層}で覚えます。
OS は「ハードとアプリの通訳」、ミドルウェアは「アプリが共通で使う裏方（DBMS、Web サーバなど）」です。
}

\section{ネットワークの考え方}

\pitfall{「IP」と「MAC」と「URL」の役割がごちゃごちゃ}{
これは住所のたとえで一気にほどけます。
\begin{itemize}
  \item \termtag{MAC アドレス}：機器に焼き付いた\textbf{機器固有の番号}（身分証番号）
  \item \termtag{IP アドレス}：ネットワーク上の\textbf{現在の居場所}（住民票の住所）
  \item \termtag{URL}：人が読むための\textbf{お店の看板}（「新宿のラーメン屋」）
\end{itemize}
URL → IP に変換する仕組みが\termtag{DNS}、IP → MAC に変換する仕組みが\termtag{ARP} です。
}

\comparisonbx{TCP と UDP}{%

\advice{%
\textbf{「確実だが遅い TCP」「速いが雑な UDP」}と覚えれば、典型問題の 8 割は解けます。
「通信品質を保証する必要がある業務系 → TCP」「リアルタイム性が必要 → UDP」の反射を作りましょう。
}

\section{データベースの基本}

\definitionbx{リレーショナルデータベース (RDB)}{
データを\textbf{表 (テーブル)} の形で持ち、表と表を\textbf{関連 (リレーション)} で結びつける方式。
SQL で操作する。一貫性を守る性質を\termtag{ACID} 特性という。
}

\comparisonbx{SQL の基本動詞}{%
\comptable{動詞 & 意味 & 生活でのたとえ}{
SELECT & 取り出す & 冷蔵庫から材料を選ぶ \\
INSERT & 入れる & 買ってきたものをしまう \\
UPDATE & 書き換える & ラベルを貼り直す \\
DELETE & 消す & 期限切れを捨てる
}
}

\pitfall{主キーと外部キーをとり違える}{
\termtag{主キー}は「その表で一意に決まる列（本人確認）」、
\termtag{外部キー}は「他の表の主キーを参照する列（つながり）」です。
\textbf{「自分を指す vs 相手を指す」}が本質的な違いです。
}

\section{セキュリティの基本}

\definitionbx{情報セキュリティの 3 要素（CIA）}{
\termtag{Confidentiality（機密性）}：見るべき人だけが見られる。
\termtag{Integrity（完全性）}：内容が正しく、改ざんされていない。
\termtag{Availability（可用性）}：必要なときに使える。
}

\pitfall{「認証」「認可」「識別」の違い}{
この 3 つは英単語も似ていて混乱します。
\begin{itemize}
  \item \termtag{識別 (Identification)}：あなたは誰？（名乗る）
  \item \termtag{認証 (Authentication)}：本当にその人？（証明する）
  \item \termtag{認可 (Authorization)}：その人に何を許す？（権限）
\end{itemize}
空港で言えば、パスポート提示が識別、顔照合が認証、セキュリティエリアの立ち入り許可が認可です。
}

ハイブリッド & 公開鍵で共通鍵を配って、中身は共通鍵で & TLS(HTTPS)
}

\section{AI と最新技術}

\pitfall{「AI」と「機械学習」と「生成 AI」の関係}{
AI ⊃ 機械学習 ⊃ ディープラーニング ⊃ 生成 AI、という\termtag{入れ子}関係です。
AI は傘の名前、機械学習はその中心的な手法、生成 AI は直近で話題の応用領域、と整理しましょう。
}

\comparisonbx{AI 関連の用語整理}{%
\comptable{用語 & 意味 & 試験での狙われ方}{
特化型 AI & 特定タスク向け & 汎用 AI との対比 \\
汎用 AI & 幅広いタスク対応 & 実現していない点が論点 \\

}

\pitfall{「IoT」と「M2M」と「エッジコンピューティング」の混同}{
\begin{itemize}
  \item \termtag{IoT}：あらゆるモノがネットにつながる\textbf{概念}
  \item \termtag{M2M}：機器同士が\textbf{自律的に}データをやり取りする仕組み
  \item \termtag{エッジコンピューティング}：データ処理を\textbf{デバイスの近く}で行う方式
\end{itemize}
IoT が広い概念、その中の通信形態の一つが M2M、処理の置き場所の話がエッジ、という層の違いを押さえます。
}

\checkquestion{通信プロトコルのうち、再送制御によって信頼性の高い通信を実現するものはどれか。}
  {UDP}
  {TCP}
  {ICMP}
  {ARP}
  {B}
  {UDP は信頼性を犠牲に速さを取る方式、ICMP は到達確認用、ARP は IP と MAC の対応解決用です。再送・順序制御を持つのは TCP のみです。}

\checkquestion{情報セキュリティの 3 要素として適切な組合せはどれか。}
  {機密性・完全性・可用性}
  {識別・認証・認可}
  {QCD}
  {SWOT}
  {A}
  {B はアクセス制御の 3 段階、C はプロジェクトの三制約、D は経営分析のフレームです。\textbf{CIA}（機密性・完全性・可用性）が情報セキュリティの基本三要素です。}
