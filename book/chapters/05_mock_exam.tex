\chapter{総仕上げ：ミニ模擬問題}

本章では、本書の全章から横断的に出題する短い模擬問題を用意しました。
すべて\textbf{オリジナル問題（ダミー）}であり、公式公開問題の引用ではありません。
実試験の形式感をつかむための練習としてご利用ください。

\section{模擬問題（10 問）}

\checkquestion{企業の経営資源を最も広く指す用語はどれか。}
  {ヒト・モノ・カネ}
  {ヒト・モノ・カネ・情報}
  {設備と現金}
  {売上と利益}
  {B}
  {近年の経営資源は「情報」まで含めるのが一般的です。A は伝統的な 3 要素、C と D は経営資源の一部だけを指します。}

\checkquestion{著作権法が保護する対象として最も適切なものはどれか。}
  {アイデアそのもの}
  {発明の技術内容}
  {表現されたもの（文章・コード・音楽など）}
  {商品の形状}
  {C}
  {A はそもそも保護対象外、B は特許法、D は意匠法の範囲です。著作権は「\textbf{アイデア}」ではなく「\textbf{表現}」を守る法律です。}

\checkquestion{プロジェクトマネジメントにおける QCD の組合せはどれか。}
  {品質・顧客・納期}
  {品質・費用・納期}
  {品質・コスト・需要}
  {品質・原価・開発}
  {B}
  {QCD は Quality（品質）・Cost（費用）・Delivery（納期）の頭文字です。用語の日本語訳ゆらぎで惑わされないようにしましょう。}

\checkquestion{TCP/IP モデルにおけるトランスポート層の代表的なプロトコルはどれか。}
  {HTTP}
  {IP}
  {TCP}
  {Ethernet}
  {C}
  {HTTP はアプリケーション層、IP はインターネット層、Ethernet はネットワークインタフェース層のプロトコルです。}

\checkquestion{リレーショナルデータベースで、表の各行を一意に識別するために指定する列の役割はどれか。}
  {外部キー}
  {主キー}
  {インデックス}
  {ビュー}
  {B}
  {外部キーは「他の表を参照する列」、インデックスは「検索を速くする仕組み」、ビューは「仮想的な表」です。本人確認に当たるのが主キーです。}

\checkquestion{情報セキュリティの 3 要素に含まれないものはどれか。}
  {機密性}
  {完全性}
  {可用性}
  {真正性}
  {D}
  {CIA（機密性・完全性・可用性）が 3 要素の定義です。真正性は「拡張した 7 要素」の一つとして扱われることがあり、3 要素には含まれません。}

\checkquestion{ハイブリッド暗号方式が使われている代表例はどれか。}
  {USB メモリの全体暗号化}
  {HTTPS（TLS）通信}
  {ファイルの個別パスワード保護}
  {ZIP の標準パスワード保護}
  {B}
  {TLS は「公開鍵で共通鍵を安全に配り、以降は速い共通鍵で通信する」ハイブリッド方式の代表例です。}

\checkquestion{アジャイル開発の特徴として適切でないものはどれか。}
  {短い反復で計画と実装を繰り返す。}
  {事前に全要件を固めることを最優先とする。}
  {変化への対応を重視する。}
  {顧客との継続的な対話を重視する。}
  {B}
  {B はウォーターフォールの発想です。アジャイル宣言では「計画に従うことよりも\textbf{変化への対応}を重視する」としています。}

\checkquestion{個人情報保護法における「個人情報」の説明として最も適切なものはどれか。}
  {機密指定された社内文書全般}
  {個人を識別できる情報（氏名・住所など）}
  {有料会員の購買履歴のみ}
  {匿名加工後のすべてのデータ}
  {B}
  {A は機密情報、C と D は対象範囲を狭く / 広く取り違えています。個人を「識別できる」かどうかが判定基準です。}

\checkquestion{SLA と SLM の関係として最も適切なものはどれか。}
  {SLA は契約、SLM はその運用・改善活動である。}
  {SLA はサービス提供、SLM は費用管理である。}
  {SLA と SLM は同義である。}
  {SLM は SLA を廃止するための仕組みである。}
  {A}
  {SLA は「約束（契約）」、SLM はその約束を守り続け改善していく「管理活動」です。静的な合意と、動的な運用の関係にあります。}

\section{公式過去問ダイジェスト（令和5年度）}

本節では、独立行政法人情報処理推進機構（IPA）が公開している
\textbf{令和5年度 ITパスポート試験 公開問題}から、分野バランスをみて代表問題を選び、
本書の学習観点（関係性・つまずき・比較）に沿って解説します。

\begin{adviceinline}
\textbf{出典}：独立行政法人情報処理推進機構『令和5年度 ITパスポート試験 公開問題』
（\copyright 2023 独立行政法人情報処理推進機構）。
各問の末尾に問題番号を付記しています。問題文はすべて公開問題の原文に基づきます。
\end{adviceinline}

\subsection{ストラテジ系から}

\checkquestion{新しいビジネスモデルや製品を開発する際に、仮説に基づいて実用に向けた最小限のサービスや製品を作り、短期に顧客価値の検証を繰り返すことによって、新規事業などを成功させる可能性を高める手法を示す用語はどれか。〔令和5年度 問1〕}
  {カニバリゼーション}
  {業務モデリング}
  {デジタルトランスフォーメーション}
  {リーンスタートアップ}
  {D}
  {\textbf{関係で覚える}：アとウは事業全体を指す用語、イは業務分析の手法。短い反復で「最小限の製品（MVP）を試す→検証する→改善する」サイクルを回すのが\termtag{リーンスタートアップ}。アジャイル開発の発想を経営に適用したもの、と捉えると記憶に残ります。}

\checkquestion{企業でのRPAの活用方法として、最も適切なものはどれか。〔令和5年度 問5〕}
  {M\&Aといった経営層が行う重要な戦略の採択}
  {個人の嗜好に合わせたサービスの提供}
  {潜在顧客層に関する大量の行動データからの規則性抽出}
  {定型的な事務処理の効率化}
  {D}
  {RPA（Robotic Process Automation）は\textbf{ルールベースの定型作業の自動化}が主戦場。Cは機械学習、Bはレコメンデーション、Aは人間の戦略判断。用語の「Robotic」に引っ張られてAIと混同しないのが試験的ポイントです。}

\checkquestion{IoTやAIといったITを活用し、戦略的にビジネスモデルの刷新や新たな付加価値を生み出していくことなどを示す言葉として、最も適切なものはどれか。〔令和5年度 問11〕}
  {デジタルサイネージ}
  {デジタルディバイド}
  {デジタルトランスフォーメーション}
  {デジタルネイティブ}
  {C}
  {DX系は「技術の話ではなく経営の話」。アは電子看板、イは情報格差、エは世代の呼称で、いずれも\textbf{経営戦略の刷新}を意味しません。DX は「ビジネスモデルや組織そのものを変える」ことを指します。}

\checkquestion{フリーミアムの事例として、適切なものはどれか。〔令和5年度 問21〕}
  {購入した定額パスをもっていれば、期限内は何杯でもドリンクをもらえるファーストフード店のサービス}
  {無料でダウンロードして使うことはできるが、プログラムの改変は許されていない統計解析プログラム}
  {名刺を個人で登録・管理する基本機能を無料で提供し、社内関係者との間での顧客情報の共有や人物検索などの追加機能を有料で提供する名刺管理サービス}
  {有料広告を収入源とすることによって、無料で配布している地域限定の生活情報などの広報誌}
  {C}
  {フリーミアム＝\textbf{Free + Premium}。基本無料・高度機能有料のモデル。アはサブスク型、イはフリーウェア（自由度の制限あり）、エは広告モデル。構造で見ると誤選択肢が消せます。}

\subsection{マネジメント系から}

\checkquestion{サービスデスクの業務改善に関する記述のうち、最も適切なものはどれか。〔令和5年度 問36〕}
  {サービスデスクが受け付けた問合せの内容や回答、費やした時間などを記録して分析を行う。}
  {障害の問合せに対して一時的な回避策は提示せず、根本原因及び解決策の検討に注力する体制を組む。}
  {利用者が問合せを速やかに実施できるように、問合せ窓口は問合せの種別ごとにできるだけ細かく分ける。}
  {利用者に対して公平性を保つように、問合せ内容の重要度にかかわらず受付順に回答を実施するように徹底する。}
  {A}
  {サービスデスクの改善は\textbf{データを取って分析する}のが基本。イは利用者の業務継続性を無視、ウは利用者を迷わせ、エは重要度の概念を欠きます。「改善＝計測 → 分析 → 施策」のループは本書 02 章のサービスマネジメントと一貫します。}

\checkquestion{運用中のソフトウェアの仕様書がないので、ソースコードを解析してプログラムの仕様書を作成した。この手法を何というか。〔令和5年度 問39〕}
  {コードレビュー}
  {デザインレビュー}
  {リバースエンジニアリング}
  {リファクタリング}
  {C}
  {「成果物→仕様」と\textbf{時間を逆流}させるのがリバースエンジニアリング。エは仕様を変えずに内部構造を改善する別概念。両者を混同しないのが頻出ひっかけです。}

\checkquestion{A社のIT部門では、ヘルプデスクのサービス可用性の向上を図るために、対応時間を24時間に拡大することを検討している。（中略）この合意に用いる文書として、最も適切なものはどれか。〔令和5年度 問44〕}
  {BCP}
  {NDA}
  {SLA}
  {SLM}
  {C}
  {サービス品質の\textbf{合意文書}はSLA。SLMは「SLAを守って改善していく活動」で、書面ではなく運用プロセスです。BCPは事業継続計画、NDAは秘密保持契約。}

\checkquestion{リファクタリングの説明として、適切なものはどれか。〔令和5年度 問49〕}
  {ソフトウェアが提供する機能仕様を変えずに、内部構造を改善すること}
  {ソフトウェアの動作などを解析して、その仕様を明らかにすること}
  {ソフトウェアの不具合を修正し、仕様どおりに動くようにすること}
  {利用者の要望などを基に、ソフトウェアに新しい機能を加える修正をすること}
  {A}
  {\textbf{外から見た振る舞いは変えない}のが要点。イはリバースエンジニアリング、ウはバグ修正、エは機能追加で、どれも「内部構造の整理」という本質からはズレます。}

\subsection{テクノロジ系から}

\checkquestion{Webサイトなどに不正なソフトウェアを潜ませておき、PCやスマートフォンなどのWebブラウザからこのサイトにアクセスしたとき、利用者が気付かないうちにWebブラウザなどの脆弱性を突いてマルウェアを送り込む攻撃はどれか。〔令和5年度 問58〕}
  {DDoS攻撃}
  {SQLインジェクション}
  {ドライブバイダウンロード}
  {フィッシング攻撃}
  {C}
  {「アクセスしただけで感染」＝\textbf{運転中にポイ捨て（drive-by）}のイメージ。アはサービス停止、イはDBへの命令混入、エは偽サイトで情報を釣る攻撃。\textbf{攻撃対象}で分けて覚えるのが近道です。}

\checkquestion{情報セキュリティにおける認証要素は3種類に分類できる。認証要素の3種類として、適切なものはどれか。〔令和5年度 問62〕}
  {個人情報、所持情報、生体情報}
  {個人情報、所持情報、知識情報}
  {個人情報、生体情報、知識情報}
  {所持情報、生体情報、知識情報}
  {D}
  {認証の3要素は「\textbf{知識（Something you know）}・\textbf{所持（Something you have）}・\textbf{生体（Something you are）}」。個人情報は要素ではなく\textbf{識別}の話。3要素と識別・認証・認可（本書03章）を合わせて押さえてください。}

\checkquestion{インターネット上のコンピュータでは、Webや電子メールなど様々なアプリケーションプログラムが動作し、それぞれに対応したアプリケーション層の通信プロトコルが使われている。これらの通信プロトコルの下位にあり、基本的な通信機能を実現するものとして共通に使われる通信プロトコルはどれか。〔令和5年度 問68〕}
  {FTP}
  {POP}
  {SMTP}
  {TCP/IP}
  {D}
  {アプリ層の下にある「共通基盤」は\textbf{TCP/IP}。ア・イ・ウはすべてアプリケーション層のプロトコル。本書03章の\textbf{階層図}を思い出せば、どの層の話かで選択肢が半分に絞れます。}

\checkquestion{サブネットマスクの役割として、適切なものはどれか。〔令和5年度 問97〕}
  {IPアドレスから、利用しているLAN上のMACアドレスを導き出す。}
  {IPアドレスの先頭から何ビットをネットワークアドレスに使用するかを定義する。}
  {コンピュータをLANに接続するだけで、TCP/IPの設定情報を自動的に取得する。}
  {通信相手のドメイン名とIPアドレスを対応付ける。}
  {B}
  {サブネットマスクは IP アドレスを「\textbf{ネットワーク部}」と「\textbf{ホスト部}」に分ける\textbf{物差し}。アはARP、ウはDHCP、エはDNSの役割。\textbf{どの技術がどの変換をするか}という対応関係で全体を捉えてください。}
