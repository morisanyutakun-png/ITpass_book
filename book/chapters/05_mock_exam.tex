\chapter{総仕上げ：模擬問題と公式過去問}

本章では、これまでの学習を「\textbf{出力}」に変えます。
まずは本書編集部の\textbf{オリジナル問題}で出題形式に慣れ、
続いて\textbf{令和5年度 ITパスポート試験 公開問題}から選んだ代表問題で実力を確認します。

\begin{adviceinline}
\textbf{出典について}：本章第 2 節に収録する問題は、
独立行政法人情報処理推進機構（IPA）が公表している
『令和5年度 ITパスポート試験 公開問題』（\copyright 2023 独立行政法人情報処理推進機構）に基づきます。
問題文は公開問題の記述を尊重し、学習目的の範囲で引用します。
各問の末尾に元の問題番号を付記しています。
\end{adviceinline}

\section{オリジナル模擬問題（10 問）}

以下はすべて本書編集部による\textbf{オリジナル問題（ダミー）}です。

\checkquestion{企業の経営資源を最も広く指す用語はどれか。}
  {ヒト・モノ・カネ}
  {ヒト・モノ・カネ・情報}
  {設備と現金}
  {売上と利益}
  {B}
  {近年の経営資源は「情報」まで含めるのが一般的です。A は伝統的な 3 要素、C と D は経営資源の一部だけを指します。}

\checkquestion{著作権法が保護する対象として最も適切なものはどれか。}
  {アイデアそのもの}
  {発明の技術内容}
  {表現されたもの（文章・コード・音楽など）}
  {商品の形状}
  {C}
  {A はそもそも保護対象外、B は特許法、D は意匠法の範囲です。著作権は「\textbf{アイデア}」ではなく「\textbf{表現}」を守る法律です。}

\checkquestion{プロジェクトマネジメントにおける QCD の組合せはどれか。}
  {品質・顧客・納期}
  {品質・費用・納期}
  {品質・コスト・需要}
  {品質・原価・開発}
  {B}
  {QCD は Quality（品質）・Cost（費用）・Delivery（納期）の頭文字です。用語の日本語訳ゆらぎで惑わされないようにしましょう。}

\checkquestion{TCP/IP モデルにおけるトランスポート層の代表的なプロトコルはどれか。}
  {HTTP}
  {IP}
  {TCP}
  {Ethernet}
  {C}
  {HTTP はアプリケーション層、IP はインターネット層、Ethernet はネットワークインタフェース層のプロトコルです。}

\checkquestion{リレーショナルデータベースで、表の各行を一意に識別するために指定する列の役割はどれか。}
  {外部キー}
  {主キー}
  {インデックス}
  {ビュー}
  {B}
  {外部キーは「他の表を参照する列」、インデックスは「検索を速くする仕組み」、ビューは「仮想的な表」です。本人確認に当たるのが主キーです。}

\checkquestion{情報セキュリティの 3 要素に含まれないものはどれか。}
  {機密性}
  {完全性}
  {可用性}
  {真正性}
  {D}
  {CIA（機密性・完全性・可用性）が 3 要素の定義です。真正性は「拡張した 7 要素」の一つとして扱われることがあり、3 要素には含まれません。}

\checkquestion{ハイブリッド暗号方式が使われている代表例はどれか。}
  {USB メモリの全体暗号化}
  {HTTPS（TLS）通信}
  {ファイルの個別パスワード保護}
  {ZIP の標準パスワード保護}
  {B}
  {TLS は「公開鍵で共通鍵を安全に配り、以降は速い共通鍵で通信する」ハイブリッド方式の代表例です。}

\checkquestion{アジャイル開発の特徴として適切でないものはどれか。}
  {短い反復で計画と実装を繰り返す。}
  {事前に全要件を固めることを最優先とする。}
  {変化への対応を重視する。}
  {顧客との継続的な対話を重視する。}
  {B}
  {B はウォーターフォールの発想です。アジャイル宣言では「計画に従うことよりも\textbf{変化への対応}を重視する」としています。}

\checkquestion{個人情報保護法における「個人情報」の説明として最も適切なものはどれか。}
  {機密指定された社内文書全般}
  {個人を識別できる情報（氏名・住所など）}
  {有料会員の購買履歴のみ}
  {匿名加工後のすべてのデータ}
  {B}
  {A は機密情報、C と D は対象範囲を狭く／広く取り違えています。個人を「識別できる」かどうかが判定基準です。}

\checkquestion{SLA と SLM の関係として最も適切なものはどれか。}
  {SLA は契約、SLM はその運用・改善活動である。}
  {SLA はサービス提供、SLM は費用管理である。}
  {SLA と SLM は同義である。}
  {SLM は SLA を廃止するための仕組みである。}
  {A}
  {SLA は「約束（契約）」、SLM はその約束を守り続け改善していく「管理活動」です。静的な合意と、動的な運用の関係にあります。}

\section{公式過去問ダイジェスト（令和5年度 公開問題）}

本節の問題はすべて、IPA『令和5年度 ITパスポート試験 公開問題』（\copyright 2023 独立行政法人情報処理推進機構）からの出題です。
問題番号は元の公開問題に準拠しています。

\subsection{ストラテジ系（10 問）}

\checkquestion{新しいビジネスモデルや製品を開発する際に、仮説に基づいて実用に向けた最小限のサービスや製品を作り、短期に顧客価値の検証を繰り返すことによって、新規事業などを成功させる可能性を高める手法を示す用語はどれか。〔令和5年度 問1〕}
  {カニバリゼーション}
  {業務モデリング}
  {デジタルトランスフォーメーション}
  {リーンスタートアップ}
  {D}
  {\textbf{構造で覚える}：アとウは事業全体を指す用語、イは業務分析手法。短い反復で「最小限の製品（MVP）を試す→検証→改善」のサイクルが\termtag{リーンスタートアップ}です。}

\checkquestion{次の a〜c のうち、著作権法によって定められた著作物に該当するものだけを全て挙げたものはどれか。 a: 原稿なしで話した講演の録音 ／ b: 時刻表に掲載されたバスの到着時刻 ／ c: 創造性の高い技術の発明〔令和5年度 問2〕}
  {a のみ}
  {a, c}
  {b, c}
  {c のみ}
  {A}
  {著作権は\textbf{「表現」}を守ります。時刻表はありふれた事実、発明は特許法の対象。即興の講演録音は\textbf{思想・感情の表現}として著作物に該当します。}

\checkquestion{観光などで訪日した外国人が国内にもたらす経済効果を示す言葉として、最も適切なものはどれか。〔令和5年度 問3〕}
  {アウトソーシング}
  {アウトバウンド需要}
  {インキュベーター}
  {インバウンド需要}
  {D}
  {「\textbf{入ってくる}」がインバウンド、「\textbf{出ていく}」がアウトバウンド。日本へ来る外国人の消費は\textbf{インバウンド需要}です。}

\checkquestion{企業での RPA の活用方法として、最も適切なものはどれか。〔令和5年度 問5〕}
  {M\&A といった経営層が行う重要な戦略の採択}
  {個人の嗜好に合わせたサービスの提供}
  {潜在顧客層に関する大量の行動データからの規則性抽出}
  {定型的な事務処理の効率化}
  {D}
  {RPA（Robotic Process Automation）は\textbf{ルールベースの定型作業の自動化}が主戦場。C は機械学習、B はレコメンデーション、A は人間の戦略判断。}

\checkquestion{経営戦略に基づいて策定される情報システム戦略の責任者として、最も適切なものはどれか。〔令和5年度 問7〕}
  {CIO}
  {基幹システムの利用部門の部門長}
  {システム開発プロジェクトマネージャ}
  {システム企画担当者}
  {A}
  {情報システム戦略の\textbf{責任者}は\textbf{CIO（最高情報責任者）}。利用部門長・PM・企画担当は「実行側」であり、戦略の最終責任者ではありません。}

\checkquestion{IoT や AI といった IT を活用し、戦略的にビジネスモデルの刷新や新たな付加価値を生み出していくことなどを示す言葉として、最も適切なものはどれか。〔令和5年度 問11〕}
  {デジタルサイネージ}
  {デジタルディバイド}
  {デジタルトランスフォーメーション}
  {デジタルネイティブ}
  {C}
  {DX は「技術ではなく経営の話」。ア＝電子看板、イ＝情報格差、エ＝世代の呼称。いずれも\textbf{経営の変革}を指しません。}

\checkquestion{AI の活用領域の一つである自然言語処理が利用されている事例として、適切なものだけを全て挙げたものはどれか。 a: Web サイト上での翻訳 ／ b: SNS 投稿の文字情報からの被災状況把握 ／ c: スマートスピーカーによる音声操作 ／ d: 駐車場のナンバープレートを文字認識して自動開錠〔令和5年度 問14〕}
  {a, b, c}
  {a, b, d}
  {a, c, d}
  {b, c, d}
  {A}
  {自然言語処理は\textbf{文字や音声の言語データ}を扱う技術。d のナンバープレート認識は\textbf{画像処理}が主で、文字認識はするものの\textbf{言語処理}とは別カテゴリです。}

\checkquestion{フリーミアムの事例として、適切なものはどれか。〔令和5年度 問21〕}
  {定額パスで期限内ドリンク無料のファーストフード}
  {無料配布だが改変は禁止されている統計解析プログラム}
  {名刺管理の基本機能が無料で、共有などの追加機能が有料}
  {有料広告を収入源として無料配布する地域広報誌}
  {C}
  {フリーミアム＝\textbf{Free + Premium}。基本無料・高度機能有料の構造。ア＝サブスク、イ＝フリーウェア、エ＝広告モデル。}

\checkquestion{資本活用の効率性を示す指標はどれか。〔令和5年度 問20〕}
  {売上高営業利益率}
  {自己資本比率}
  {総資本回転率}
  {損益分岐点比率}
  {C}
  {効率性の問いには\textbf{回転系}で答える。利益率＝収益性、自己資本比率＝安全性、損益分岐点比率＝余裕度、と観点が違います。}

\checkquestion{OMG によって維持されており、国際規格 ISO/IEC 19510 として標準化されているビジネスプロセスのモデリング手法及び表記法はどれか。〔令和5年度 問23〕}
  {BABOK}
  {BPMN}
  {BPO}
  {BPR}
  {B}
  {BPMN（Business Process Model and Notation）はビジネスプロセスの\textbf{図式表記}の標準。BABOK はビジネス分析知識体系、BPO は業務の外部委託、BPR は業務改革。}

\subsection{マネジメント系（8 問）}

\checkquestion{サービスデスクの業務改善に関する記述のうち、最も適切なものはどれか。〔令和5年度 問36〕}
  {受け付けた問合せの内容や回答、費やした時間などを記録して分析を行う。}
  {一時的な回避策は提示せず、根本原因及び解決策の検討に注力する。}
  {問合せ窓口は問合せの種別ごとにできるだけ細かく分ける。}
  {重要度にかかわらず受付順に回答するように徹底する。}
  {A}
  {サービスデスク改善は\textbf{データを取って分析}が基本。他は利用者体験や業務継続性を軽視した案です。}

\checkquestion{システム開発プロジェクトの品質目標を検討するために、複数の類似プロジェクトのプログラムステップ数と不良件数の関係性を示す図として、適切なものはどれか。〔令和5年度 問38〕}
  {管理図}
  {散布図}
  {特性要因図}
  {パレート図}
  {B}
  {2 変数の\textbf{相関}を見るのは\textbf{散布図}。管理図は時系列の異常検出、特性要因図は原因の構造化、パレート図は重み付けが目的です。}

\checkquestion{運用中のソフトウェアの仕様書がないので、ソースコードを解析してプログラムの仕様書を作成した。この手法を何というか。〔令和5年度 問39〕}
  {コードレビュー}
  {デザインレビュー}
  {リバースエンジニアリング}
  {リファクタリング}
  {C}
  {\textbf{成果物から仕様へ}と時間を逆流させるのがリバースエンジニアリング。リファクタリングは「\textbf{仕様を変えずに}内部構造を整える」別概念です。}

\checkquestion{ソフトウェア開発における DevOps に関する記述として、最も適切なものはどれか。〔令和5年度 問40〕}
  {要件定義段階でプロトタイプを作成する。}
  {設計・開発・テストを順に実施して運用側に引き渡す。}
  {開発側と運用側が密接に連携し、自動化ツールなどを取り入れて仕様変更に迅速に対応する。}
  {一つのプログラムを 2 人の開発者が共同で開発する。}
  {C}
  {DevOps の本質は\textbf{開発（Dev）と運用（Ops）の連携}。ア＝プロトタイピング、イ＝ウォーターフォール、エ＝ペアプログラミング。}

\checkquestion{プロジェクトマネジメントでは、スケジュール、コスト、品質といった競合する制約条件のバランスをとることが求められる。計画していた開発スケジュールを短縮することになった場合の対応として、適切なものはどれか。〔令和5年度 問45〕}

  {提供するシステムの高機能化を図ってスケジュールを遵守することを検討する。}
  {プロジェクトの対象スコープを拡大してスケジュールを遵守することを検討する。}
  {プロジェクトメンバーを削減してスケジュールを遵守することを検討する。}
  {A}
  {QCD の常識に従うのはアのみ。高機能化・スコープ拡大・メンバー削減はいずれも\textbf{三制約のバランスを崩す}誤答です。}

\checkquestion{ある企業の IT 部門では、ヘルプデスクの対応時間を 24 時間に拡大することを検討している。受託企業が「深夜は自動応答で対応する」と提案し、合意に至った。この合意に用いる文書として、最も適切なものはどれか。〔令和5年度 問44〕}

  {NDA}
  {SLA}

\checkquestion{リファクタリングの説明として、適切なものはどれか。〔令和5年度 問49〕}
  {機能仕様を変えずに、内部構造を改善すること}

  {\textbf{外から見た振る舞いは変えない}のが要点。イ＝リバースエンジニアリング、ウ＝バグ修正、エ＝機能追加。}

\checkquestion{内部統制において、不正防止を目的とした職務分掌に関する事例として、最も適切なものはどれか。〔令和5年度 問50〕}

\subsection{テクノロジ系（12 問）}

\checkquestion{ISMS クラウドセキュリティ認証に関する記述として、適切なものはどれか。〔令和5年度 問56〕}
  {PaaS、SaaS が対象であり、IaaS は対象ではない。}

  {クラウドサービスを提供している組織が対象であり、利用する組織は対象ではない。}
  {クラウドに保管される個人情報保護の体制を評価してプライバシーマークの使用を認める制度である。}
  {B}
  {ISMS クラウドセキュリティ認証は\textbf{クラウド固有の管理策}を評価する認証です。対象範囲・プライバシーマークとの混同に注意。}

\checkquestion{IoT デバイスにおけるセキュリティ対策のうち、耐タンパ性をもたせる対策として、適切なものはどれか。〔令和5年度 問57〕}
  {サーバからの接続認証が連続して一定回数失敗したら接続できないようにする。}
  {通信するデータを暗号化し、データの機密性を確保する。}
  {内蔵ソフトウェアにオンラインアップデート機能を持たせ、最新のパッチが適用されるようにする。}
  {内蔵ソフトウェアを難読化し、解読に要する時間を増大させる。}
  {D}
  {耐タンパ性は\textbf{「解析・改ざんされにくい」}性質。難読化がそれに直接効きます。他は別の脆弱性に対する対策です。}

  {SQL インジェクション}
  {ドライブバイダウンロード}
  {フィッシング攻撃}
  {C}
  {「アクセスしただけで感染」＝\textbf{drive-by}。ア＝サービス停止、イ＝DB への命令混入、エ＝偽サイトで情報を釣る。}

\checkquestion{情報セキュリティにおける認証要素は 3 種類に分類できる。認証要素の 3 種類として、適切なものはどれか。〔令和5年度 問62〕}
  {個人情報、所持情報、生体情報}
  {個人情報、所持情報、知識情報}
  {個人情報、生体情報、知識情報}
