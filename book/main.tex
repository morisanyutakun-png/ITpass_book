この本は、\textbf{「読むだけの参考書」}でも\textbf{「解くだけの問題集」}でもありません。

\textbf{「図で理解し、その場で解いて、解説でひっかけを潰す」}

——この1冊で、理解と演習を同時に回せるように設計しました。

\begin{itemize}
  \item \textbf{左ページ}には、要点整理と問題を配置
  \item \textbf{右ページ}には、解答と「なぜ他の選択肢がダメか」まで踏み込んだ解説
  \item \textbf{章末}には、ミニ模試で理解度を確認
  \item \textbf{巻末}には、本試験形式の模試を収録
\end{itemize}

ITパスポートは「暗記で受かる」と言われがちですが、実際には\textbf{「似た用語の見分け方」}を知っているかどうかで合否が分かれます。
本書は、その「見分け方」を問題の中で体験しながら身につけることを目指しています。

\vspace{1em}
\noindent 対象読者：大学生・就活生・新社会人・非IT系初学者・一度挫折した再受験者
