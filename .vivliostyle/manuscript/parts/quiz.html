ミニテスト（10 問）

:::mini-quiz Q1. プロジェクトマネジメントにおける QCD の組合せはどれか。

  1. 品質・顧客・納期
  2. 品質・費用・納期
  3. 品質・コスト・需要
  4. 品質・原価・開発

::::answer 正解 : 2　QCD は Quality（品質）・Cost（費用）・Delivery（納期）。 日本語訳のゆらぎに惑わされないようにします。 :::: :::

:::mini-quiz Q2. TCP/IP モデルにおけるトランスポート層の代表的なプロトコルはどれか。

  1. HTTP
  2. IP
  3. TCP
  4. Ethernet

::::answer 正解 : 3　HTTP はアプリ層、IP はインターネット層、Ethernet はネットワークインタフェース層です。 :::: :::

:::mini-quiz Q3. 情報セキュリティの 3 要素に含まれないものはどれか。

  1. 機密性
  2. 完全性
  3. 可用性
  4. 真正性

::::answer 正解 : 4　CIA は機密性・完全性・可用性の 3 要素。 真正性は拡張 7 要素に含まれますが、基本 3 要素には入りません。 :::: :::

:::mini-quiz Q4. 関係データベースで、表の各行を一意に識別するために指定する列の役割はどれか。

  1. 外部キー
  2. 主キー
  3. インデックス
  4. ビュー

::::answer 正解 : 2　外部キーは他の表を参照する列、インデックスは検索を速くする仕組み、ビューは仮想的な表です。 :::: :::

:::mini-quiz Q5. SWOT 分析で扱うのはどれか。

  1. 市場の成長率と占有率
  2. 自社の強み・弱みと、外部の機会・脅威
  3. 製品・価格・流通・販促の 4 要素
  4. 顧客・競合・自社の 3 視点

::::answer 正解 : 2　1 は PPM、3 は 4P、4 は 3C です。 SWOT は「自社の健康診断 + 外部環境の風向き」。 :::: :::
