CHAPTER 00

はじめに

:::chapter-lead この本は、ITパスポートを「暗記」ではなく「理解」で受かるための参考書です。
用語の羅列ではなく、図と関係性とつまずきの理由から学びます。 ::: :::

本書の 3 つの約束

:::point-box

  • 図で見せる：各章のはじめに「1 枚でわかる構造図」を置きます。
  • 関係で覚える：新しい用語は、既出の用語との関係で紹介します。
  • ひっかけの理由まで書く：答えだけでなく「他の選択肢がなぜ違うか」を説明します。 :::

想定読者

本書は、次のような方を念頭に書かれています。

  • 大学生・就活生・新社会人
  • 非 IT 系でこれから IT パスポートを受ける方
  • 一度挫折した再受験者
  • 高校生や専門学校生など、これから IT の土台を作りたい方

ITの前提知識はいりません。 ただし「やさしいだけ」にはしません。本質を削らず、でも急がず、ゆっくり説明します。

認知科学に基づく 3 周の読み方

この本は「1 回で覚えきる」ことを前提にしていません。 短い時間を分けて、記憶に定着させていくほうが、はるかに効率がよいことが知られています。

:::compare-table | 周 | 目的 | 読み方 | | :-- | :-- | :-- | | 1 周目 | 全体像をつかむ | 各章冒頭の構造図と「1 枚まとめ」だけを読む | | 2 周目 | 比較で覚える | 本文を通読。比較表・つまずきを重点的に | | 3 周目 | 出力に変える | 章末問題・巻末ミニテストで、間違えた節だけ戻る | :::

:::caution-box ### 一夜漬けは、IT パスポートとの相性が悪い 試験範囲は広く、出題も分野横断です。 "前日に詰め込む" より、"短く何度も回す" ほうが記憶に残ります。 本書は、まさにその繰り返し用に設計されています。 :::

本書で使う「役者」

誌面にはいくつかの役者が登場します。最初にかたちを覚えておくと、どこに注目すればいいかがわかります。

:::point-box ### 要点（ここは押さえる、という合図） 学習テーマの核心を、短い言葉で示します。 :::

:::caution-box ### つまずき（ここでよく止まる、という合図） 初学者が混乱しやすい場所を、先回りして説明します。 :::

:::exam-trap-box ### ひっかけ（本試験で狙われる、という合図） 似た用語や定義の境界線を、選択肢の形式で確認します。 :::

:::summary-card ### この節のまとめ

  • 本書は 3 周読みを前提にした資格教材。
  • 各節は「つまずき → 直感 → 定義 → 比較 → 出題 → 1 問確認」の順で構成される。
  • 役者（要点／つまずき／ひっかけ／まとめ）の色と形で、いま何を読んでいるかが常にわかる。 :::

:::mini-quiz Q. 本書が推奨する学習法として、最も適切なものはどれか。

  1. 1 周で完璧に覚えきる
  2. 章末問題は読むだけで、解かない
  3. 3 周する前提で、1 周目はスピード重視、3 周目で問題を解く
  4. 用語を五十音順に暗記する

::::answer 正解 : 3　3 周読みは、忘却曲線を踏まえた合理的な読み方です。 「1 周で完璧」を目指すと、広い試験範囲に対して息切れしやすくなります。 :::: :::
