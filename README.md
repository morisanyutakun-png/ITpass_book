# 図で解ける ITパスポート

**副題**: 理解しながら解く、見開き完結の問題集

本リポジトリは、ITパスポート試験の問題集本体（LaTeX）と、読者向けの静的サポートサイト（GitHub Pages）を一体で管理するプロジェクトです。

---

## プロジェクトの目的

大学生・新社会人・非IT系初学者を対象に、

- **左ページで理解し、右ページで解く** 見開き完結型
- **ひっかけの理由まで解説する** 誤答分析つき
- **図解と問題が直結する** 理解導線型

の ITパスポート問題集を作ります。完全な教科書でも、完全な模試集でもない、**「理解できる問題集」** です。

---

## 本のコンセプト

**「図で理解し、その場で解いて、解説でひっかけを潰す」**

| 従来の参考書 | 従来の問題集 | この本 |
|---|---|---|
| 説明が長い、問題が少ない | 問題だけ、理解が浅い | 理解と出力が1見開きで回る |
| 読んで終わり | 解いて終わり | 読んで→解いて→なぜ間違えるか分かる |
| 教科書感が強い | 薄い解説 | 誤答の理由まで可視化 |

---

## 想定読者

- 大学生・就活生
- 新社会人
- 非IT系初学者
- 一度挫折した再受験者

## 本の構成

### 基本フォーマット：1テーマ1見開き

| 左ページ（理解補助） | 右ページ（出力） |
|---|---|
| テーマタイトル | 4択問題 2〜3問 |
| つまずきポイント | 難易度ラベル（基礎/標準/ひっかけ） |
| 直感的なたとえ | 正解＋解説 |
| 最低限の定義 | 他選択肢がなぜ違うか |
| 比較表・小さめの図解 | ひっかけポイント |
| 「ここが誤答ポイント」1行メモ | 関連テーマへの戻り先 |
| 1枚で見える要点整理 | 「1行で言うと何が大事か」 |

### 章構成

| 章 | 内容 | 狙い |
|---|---|---|
| 第1章 | 導入と全体像 | 試験の構造・本の使い方・自己診断 |
| 第2章 | ストラテジ系 | 経営・財務・法務を見開き問題集化 |
| 第3章 | マネジメント系 | 開発・プロマネ・サービス運用を見開き問題集化 |
| 第4章 | テクノロジ系 | HW・NW・DB・セキュリティ・AIを見開き問題集化 |
| 第5章 | 分野横断とひっかけ攻略 | 横断テーマ別問題・誤答パターン集 |
| 第6章 | 総仕上げ模試 | 分野別ミニ模試＋本試験形式模試 |

### 問題の分類

本書では、問題の出典を明確に分離して管理します。

- **オリジナル問題**: 本書の説明文から自然に構成した確認問題（`original` タグ）
- **公式由来問題**: IPA公開の過去問から引用・改変した問題（`source` / `year` / `question_no` を保持）
- **章末ミニ模試**: 各章の総復習用（オリジナル＋公式混合可）
- **巻末模試**: 本試験形式100問（公式由来中心）

## book のビルド方法

**前提**: TeX Live 2022 以降、LuaLaTeX、luatexja、`latexmk`、`qrcode`、`tikz` が利用可能であること。

```bash
cd book
latexmk main.tex
```

または：

```bash
./scripts/build_book.sh
```

初回のみ luatexja のフォントキャッシュ生成に時間がかかることがあります。

---

## site のローカル確認方法

```bash
./scripts/serve_site.sh
# または
cd site && python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

本書の QR コードからもこのサイトにアクセスできます。テーマごとの練習問題・図解PDF・正誤表などの補助コンテンツを提供します。

---

## GitHub Pages の公開方法

1. このリポジトリを GitHub にプッシュ
2. リポジトリの **Settings → Pages → Build and deployment** で **Source = GitHub Actions** を選択
3. `main` ブランチへの push をトリガーに `.github/workflows/pages.yml` が `site/` をデプロイ

公開URLの想定: `https://<username>.github.io/<repo>/`

書籍の QR コードが指す URL は `book/styles/macros.tex` の `\supportbaseurl` で一元管理しているため、デプロイURLが決まったら 1 箇所だけ書き換えてください。

## 問題集の編集方針

### 見開きユニットの基本構造

各テーマは以下の流れで構成する：

1. **つまずきポイント** — 初学者がどこで混乱するか
2. **超要点** — 最低限の定義と直感的なたとえ
3. **比較・図解** — 1つの比較表 or 図解
4. **4択問題 2〜3問** — 基礎→比較→横断の順
5. **解説** — 正解理由＋全選択肢の誤答分析
6. **関連テーマへの接続** — 戻り先の明示

### 問題の並び順に意図を持たせる

- 1問目：基礎確認（定義を問う）
- 2問目：比較・ひっかけ（似た用語の見分け）
- 3問目：少し横断（他テーマとの接続）

### 解説の必須要素

- 正解理由
- 他選択肢がなぜ違うか（全選択肢分析）
- ひっかけポイント
- どの用語を取り違えやすいか
- 関連する比較テーマ

### 文体ルール

- 大学生・新社会人向け：やさしいが浅すぎない
- 問題集らしいテンポ：短い文、細かい見出し
- 上から目線にしない
- 読者の誤解を言語化する
- 「なぜ間違えたか」が伝わるようにする

## 過去問の取り扱い

本プロジェクトでは、問題の出典を厳密に管理します。

### オリジナル問題

本書の説明文から自然に構成した確認問題。

```json
{
  "type": "original",
  "derived_from": "テーマ名",
  "review_status": "draft | reviewed | final"
}
```

### 公式由来問題

IPA公開の過去問から引用・改変した問題。

```json
{
  "source": "IPA公式",
  "year": "R6",
  "question_no": 42,
  "notes": "選択肢の順序を変更"
}
```

### 禁止事項

- 市販参考書・問題集の問題文や解説を模倣しない
- 公式問題の近似コピーを安易に量産しない
- 出典不明の問題を公式由来として扱わない

## QR コードとサポートサイトの連携

本書の各章・各テーマには QR コードを配置し、サポートサイトの対応ページへ誘導します。

- **テーマ別練習問題**: 本書の見開き問題の類題をブラウザで演習
- **図解PDFダウンロード**: 印刷用の比較表・構造図
- **誤答パターン集**: よくある間違いの追加解説

QR コードの URL は `\supportbaseurl` マクロで一元管理し、`\qrunit{chapter}{section}` で各テーマに自動配置します。

## 権利面で注意すべき点（要確認事項）

本プロジェクトは、**市販参考書・市販問題集の問題文や解説を模倣しません**。
公式公開問題（IPA 等）を扱う場合に備えて、データ構造には出典フィールドを用意していますが、現時点のサンプル問題はすべてオリジナルです。

以下は、出版・配布前に必ず個別確認してください：

- 公式公開問題の引用範囲・再配布可否・改変可否
- 図版に第三者素材を含める場合のライセンス
- 商標（試験名など）の表記ガイドライン
- 読者提供コンテンツ（確認テスト等）の権利表示

## 運用上の考え方

- **本が主役、Web は補助**。サイトは「練習問題」「図解PDF」「正誤表」「更新案内」に役割を限定する。
- サーバ・DB・認証は使わない。すべて静的で完結させる。
- AI は執筆補助・図版補助・整形補助に使ってよいが、**内容の品質判断は人間が最終責任を持つ**。
- まず完成させ、その後保守性を整える。
